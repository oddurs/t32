# Changelog

Notable changes to the `t32` crate and the repository's other artifacts. Changes to the specification itself are recorded in Appendix D of [SPEC.md](SPEC.md), and each draft is tagged `spec-draft-<number>`.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the crate follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html). While the specification is a draft, the crate's minor version follows the draft it implements.

## [Unreleased]

### Added

- Repository furniture: `scripts/task`, the single entry point to every check; `scripts/agent`, the worktree workflow; git hooks; `CLAUDE.md`; CODEOWNERS; Dependabot; `.editorconfig` and `.gitattributes`; pinned Rust and Node toolchains; a feature-request form and a proposal form for Discussions.
- GitHub releases, made by the publish workflow from this file.

### Changed

- CI runs `scripts/task check`, and branch protection requires one aggregate status, `required`.

## [0.3.0] - 2026-11-01

Implements specification draft 0.3.

### Added

- `Stamp::upper_bound`, the exclusive upper bound of a prefix range, correct for columns of mixed lengths.
- `Instant::is_provisional`, so every conversion path reports provisional status.
- Conformance vectors: 782, every one generated by the oracle, errors included, with categories for TAI-instant encoding, binary packing, range bounds, the resolution rule, stamp plus duration, stamp minus stamp and provisional status.
- TypeScript: `upperBound`, `maxLength` and `fxIsProvisional`.
- Project governance, contribution guide, code of conduct, security policy and a list of implementations; CI gates every deploy and release.

### Changed

- `Duration::as_nanos` rounds to the nearest nanosecond, so every nanosecond count survives a round trip and the difference of instants made from nanoseconds is exact.
- UTC text errors follow the specification's order, and a `.` among a duration's digits is `invalid_char`.
- TypeScript: error codes are the specification's; parsing follows its grammar and order of errors; arguments are checked rather than wrapped.

### Fixed

- `Stamp::max_len` is exact. It used floating point and could allow one character more than the specification permits near a midpoint between lengths.
- Converting a negative `Duration` to `std::time::Duration` fails, however small; converting a long one no longer overflows.
- `SystemTime` conversion works across the whole range in both directions.
- `Sum` fails only when the total is out of range, not a partial sum.
- UTC readings follow the reading rule exactly at the edges of inserted time.

## [0.2.0] - 2026-10-31

First release on crates.io. Implements specification draft 0.2.

### Added

- `Instant`, `Stamp`, `Duration`, `UtcDateTime` and `Error`, with exact integer arithmetic throughout.
- RFC 3339 parsing and printing, and conversions to and from Unix time, TAI and `SystemTime`.
- The full TAI − UTC history from 1961, and the specification's resolution rule as `Stamp::max_len`.
- Optional serde support.
- Support for Rust 1.70 and later.
