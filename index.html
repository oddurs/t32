T32 · Draft 0.2

A compact universal timestamp

T32 writes any moment as eight characters: a count of atomic seconds since 2000, in base32. Fewer characters name a longer span, more name finer time, and sorting the text sorts the times.

How it works

  1. Count. Take the instant as seconds of International Atomic Time (TAI) since the start of 2000. TAI is the atomic time scale that UTC is derived from, and it has no leap seconds, so every second is the same length.
  2. Offset. Add 239 seconds, about 17,400 years, so that earlier dates are positive too and still sort in order.
  3. Write. Write the result in Crockford base32, five bits to a character. Eight characters count whole seconds; each character added is 32 times finer, each one removed 32 times coarser.
UTC2026-10-31 03:13:00
TAI seconds since 2000846,731,617
Plus 239550,602,545,505
In base32G0S7G6B1

Shorten it to G0S7 and it names the 12 days that contain that second. Each character narrows the span before it by a factor of 32; the playground shows the same steps for any date.

Properties

Length is resolution
Drop characters for a coarser span, add them for finer time. A stamp always names an interval, never a false instant.
Text order is time order
Sorted byte by byte, stamps are in chronological order, so a prefix is a range query.
Uniform seconds
T32 counts TAI, which has no leap seconds. From 1961 on, the difference of two stamps is the time elapsed between them.
Exact and stable
Conversion from UTC is exact at every step of the leap-second table, and a stamp, once written, keeps its meaning.

Status

T32 is a draft, published for public review. It is complete enough to implement and test against, and it will not be frozen until it has been read widely, implemented independently and questioned properly. Comments, implementations and objections are all welcome; the participation page says where they go and what they lead to.
